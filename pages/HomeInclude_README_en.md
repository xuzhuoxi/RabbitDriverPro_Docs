### 3. Description

#### 3.1 Overview
Provide professional and well-expanded game development support, including: resource loading, event management, internationalization, network management, logical service extension, audio management, UI management, Lua interpreter, local saving, game item management, etc.  

#### 3.2 Unity engine version requirements
Unity 2022.3 or higher  

#### 3.3 Platform Compatibility
PC, Mac & Linux Standalone  
Universal Windows Platform  
iOS, Android, WebGL, tvOS, Steam  

#### 3.4 Programmable Render Pipeline (SRP) Compatibility
+ Built-in rendering pipeline (Built-in): **Compatible**
+ Universal Render Pipeline (URP): **Compatible**
+ High Definition Render Pipeline (HDRP): **Compatible**

### 4 Upgrade reminder
Please **backup** your project when upgrading, delete the existing `Assets/JLGames/RabbitDriverPro` folder, and re-import. If the project still has the old `Assets/JLGames/RocketDriver` folder, delete that as well.
