### 3. 描述

#### 3.1 概述
提供专业且扩展良好的游戏开发支持，包含： 资源加载、 事件管理、 国际化、 网络管理、 逻辑服务扩展、 音频管理、 UI管理、Lua解释器、 本地保存、 游戏物品管理等。  

#### 3.2 Unity引擎版本要求
Unity 2022.3 或更高版本  

#### 3.3 平台兼容性
PC, Mac & Linux Standalone  
Universal Windows Platform  
iOS、Android、WebGL、tvOS、Steam  

#### 3.4 可编程渲染管线（SRP）兼容性
+ 内置渲染管线（Built-in）：**兼容**
+ 通用渲染管线（URP）：**兼容**
+ 高清渲染管线（HDRP）：**兼容**

### 4 升级提醒
升级时请先**备份**你的项目，删除现有的 `Assets/JLGames/RabbitDriverPro` 目录后重新导入。若工程里仍有旧目录 `Assets/JLGames/RocketDriver`，一并删除。
